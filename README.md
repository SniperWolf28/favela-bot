Favela_Bot – Termeni și condiții
Ultima actualizare: 11 septembrie 2026

1. Acceptarea termenilor
Prin adăugarea sau utilizarea Favela_Bot pe un server Discord, accepți acești termeni. Dacă nu ești de acord, nu utiliza botul.

2. Utilizarea botului
Favela_Bot este un bot Discord destinat funcțiilor de administrare, informare și automatizare configurate de administratorii serverelor. Botul trebuie utilizat în conformitate cu regulile Discord și cu legislația aplicabilă.

3. Comportament interzis
Nu este permisă folosirea botului pentru activități ilegale, abuzive, frauduloase, pentru spam sau pentru încercarea de a afecta funcționarea Discord ori a botului.

4. Disponibilitate
Botul este furnizat „așa cum este”. Pot exista perioade de indisponibilitate, erori, mentenanță sau modificări ale funcțiilor. Nu este garantată disponibilitatea permanentă.

5. Modificarea termenilor
Termenii pot fi actualizați atunci când este necesar. Versiunea publicată pe această pagină este cea aplicabilă la momentul utilizării.

6. Contact
Pentru întrebări sau probleme legate de Favela_Bot, contactează administratorul/dezvoltatorul botului prin canalul oficial de suport al proiectului.

7. Discord
Favela_Bot nu este afiliat, sponsorizat sau susținut de Discord Inc.
